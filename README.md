## Опис

Веб-застосунок «Каталог 3D-моделей для друку технічних деталей» — це SPA (Single Page Application), побудований на React + Vite. Застосунок дозволяє переглядати, фільтрувати, шукати, додавати, редагувати та видаляти 3D-моделі для друку.

## Функціонал

- 📋 **Каталог моделей** — сітка карток з фото, матеріалом, часом друку та описом
- 🔍 **Пошук** — фільтрація за назвою, категорією та матеріалом у реальному часі
- 🎛 **Фільтр за матеріалом** — TPU / PLA / PETG / ABS
- 🪟 **Модальне вікно** — детальна інформація про модель
- ⬇ **Завантаження STL/3MF** — завантаження файлів моделей з лічильником
- ➕ **Додавання моделей** — форма з завантаженням фото та STL/3MF-файлу
- ✏️ **Редагування** — зміна даних, фото та файлу моделі
- 🗑 **Видалення** — видалення моделі зі списку

## Запуск

```bash
# Встановити залежності
npm install

# Запустити dev-сервер
npm run dev
```

Застосунок відкривається за адресою: `http://localhost:5173`

## Збірка

```bash
npm run build
```
